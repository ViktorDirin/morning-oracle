# Product Requirements Document (PRD) & Dev Plan: Morning Oracle

## 1. ЧТО (Суть продукта)
Morning Oracle — это персональный PWA-ассистент. Он совмещает в себе быстрый голосовой захват идей в течение дня и умный утренний будильник, который генерирует персональный аудио-эфир (новости + список задач на день) с использованием качественного ИИ-голоса.

## 2. АРХИТЕКТУРА И СТЕК
*   **Frontend (UI & PWA):** Next.js (App Router), Tailwind CSS, Vercel.
*   **Backend (TTS & Parsing):** Python (FastAPI/Scraper), Edge-TTS, Docker (на Oracle Cloud ARM64).
*   **Database & Storage:** Supabase (PostgreSQL для текста, Storage для MP3).
*   **Дизайн:** Mobile-First. Dark Mode (Фон: `#0a0a0a`). Акценты: Teal/Cyan (`#00E5FF`) и немного Magenta (`#FF0055`) для критических элементов. 

---

## 3. ПОШАГОВЫЙ ПЛАН РАЗРАБОТКИ (Phases)

### Phase 1: Frontend MVP & Database (Исполнитель: Cursor/Claude)
**Цель:** Создать интерфейс захвата идей и связать его с базой данных.
1.  **Supabase Setup:** Создать проект, таблицы `ideas` (id, text, status: 'inbox' | 'tomorrow', created_at) и `settings` (news_topics, alarm_time).
2.  **Next.js Init:** Поднять проект, настроить строгий Dark Mode с Teal-акцентами.
3.  **Экран Capture:** Реализовать Web Speech API для диктовки голосом. Распознанный текст сохраняется в Supabase со статусом `inbox`.
4.  **Экран Inbox:** Список идей. Возможность смахнуть/отметить идею, чтобы перевести ее в статус `tomorrow`.

### Phase 2: Backend TTS Microservice (Исполнитель: Hermes Agent на сервере)
**Цель:** Поднять микросервис генерации голоса на сервере Oracle.
*Инструкция для Telegram-топика (передать Hermes):*
> "Создай в директории `~/morning_oracle_api/` проект на Python. Напиши `docker-compose.yml` и `Dockerfile` (база python:3.11-slim, архитектура linux/arm64). Сервис должен использовать библиотеку `edge-tts` (женский голос) и FastAPI. Сделай один эндпоинт POST `/generate`, который принимает текст, генерирует MP3 файл с помощью edge-tts и возвращает ссылку на него. Контейнер должен пробрасывать порт наружу для локального тестирования."

### Phase 3: PWA Alarm & Player Logic (Исполнитель: Cursor/Claude)
**Цель:** Сделать будильник, который работает на телефоне.
1.  **Настройка PWA:** Добавить manifest, чтобы приложение устанавливалось на телефон.
2.  **Экран Morning Hub:** Большие часы. Кнопка установки времени будильника.
3.  **Логика Будильника:** При активации будильника запускается воспроизведение "тишины" (silent loop), чтобы мобильный браузер не уснул.
4.  **Аудиоплеер:** По наступлению времени будильника, интерфейс скачивает готовые MP3 файлы из Supabase Storage и последовательно их проигрывает (Музыка -> Новости -> Задачи).

### Phase 4: News Scraper & Gemini LLM (Исполнитель: Hermes Agent)
**Цель:** Автоматизировать сбор данных ночью.
*Инструкция для Telegram-топика (передать Hermes):*
> "Обнови проект `~/morning_oracle_api/`. Добавь скрипт `cron_worker.py`, который запускается по расписанию ночью. Скрипт должен: 1) Читать настройки пользователя из Supabase; 2) Собирать новости по нужным темам; 3) Отправлять текст в Gemini API для суммаризации; 4) Отправлять результат в наш локальный TTS эндпоинт; 5) Загружать готовый MP3 в Supabase Storage."
